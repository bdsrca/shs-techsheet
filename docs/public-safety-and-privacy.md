# Public Safety and Privacy Statement

This repository is safe to publish because it is a technical showcase, not a production export.

It does not include:

- real student account records
- private emails
- private chat messages
- admin production data
- cookies or sessions
- environment variables
- API keys
- database credentials
- webhook secrets

The visuals are static and sanitized. The code examples are public-safe reference snippets that demonstrate policy logic without exposing production implementation details.

The live product name is public. Private implementation details are intentionally omitted.
